# 디자인 시스템

이 문서는 사이트 화면의 기준이다. 토큰은 `src/styles/tokens.css`, 구성 요소의 기본 모양은 `src/styles/base.css`에 있고, 쪽마다의 scoped style은 이 문서의 값만 쓴다.
2026-11-26 "과도하게 AI 같다"는 피드백으로 참고 연감형으로 다시 잡았다. 기록 데이터베이스처럼 표가 먼저 오고, 글자는 작고 촘촘하며, 꾸밈 없이 괘선과 글자 굵기로만 위계를 만든다.

## 원칙

- 표가 먼저다. 같은 내용을 표와 그림으로 보일 때 그림은 표 다음이거나 "그림 · 표" 전환으로 둔다.
- 서술 문단을 두지 않는다. 쪽 첫머리 리드, 절 첫머리 요약 문장, 데이터를 다시 말하는 자동 문장을 쓰지 않는다. 해석을 제한하는 정의와 주의만 표·그림 아래 각주로 쓴다.
- 큰 숫자 칸(KPI 타일)을 두지 않는다. 한 줄 수치는 요약 표(`Tiles` 구성 요소가 표로 그린다)나 정보 상자에 둔다.
- 장식을 두지 않는다: 색 띠, 그라데이션, 알약 칩, 토글 스위치, 그림자 카드, 점선 빈 상자, 번갈아 칠한 수치.
- 색은 데이터에만 쓴다. 블루·핑크·올리브(s1-s3)는 차트 계열과 선택 상태(현재 메뉴 밑줄, 고른 탭 밑줄, 고른 행 바탕)에만 쓴다. 예외는 체코지수 페이지 제목 줄의 빨간 띠 하나다(아래 "체코지수").
- 테마는 어두운 테마 하나다(2026-11-26 사용자 결정). 밝은 테마와 테마 선택(자동, 밝게, 어둡게)을 두지 않는다.
- 페이지와 항목의 제목은 내용 이름이다(드라이버 이름, "시즌별 기록"). 꾸밈말과 번호를 붙이지 않는다.
- 차트를 읽는 법을 문장으로 쓰지 않는다. 표식, 색, 축 방향은 범례와 축이 말한다(2026-11-26 2차).
- 출처는 차트와 표마다 줄을 긋고 적지 않는다. 페이지 꼬리말 "자료" 한 줄에 그 페이지가 쓰는 데이터원과 기준일만 모은다.

## 페이지 틀

모든 페이지는 아래 순서를 따른다.

- 사이트 머리: 바탕색과 아래 헤어라인. 사이트 이름(홈 링크), 전역 검색 칸, 주 메뉴 여덟 칸(시즌, 드라이버, 컨스트럭터, 팀 계보, 업그레이드, 엔진, 규정, 방법론).
- 페이지 머리(`PageHead`): 길잡이(홈 › 목록 › 이 페이지) → h1(+ 원어) → 한 줄 메타. 그다음 개체 페이지(`box`: 드라이버, 컨스트럭터, 컨스트럭터 시즌, 팀 계보)는 [왼쪽: 요약 표, 비교 링크 | 오른쪽: 정보 표]이고, 그 밖의 페이지는 요약 줄(항목 이름 위, 값 아래, 위 1px 잉크 괘선) → 선택 메뉴다. 제목 아래에 범위·출처를 확인하는 안내 줄을 두지 않는다.
- 항목(`Section`): 1px 잉크 괘선, h2와 오른쪽 메타(범위, 보기 바꾸기, 목록 링크). 그다음 표, 차트, 주.
- 꼬리말: 회색 면(괘선 없음). "자료" 한 줄(이 페이지의 데이터원과 기준일), 비공식 고지, 라이선스와 방법론 링크.

개체 페이지(드라이버, 컨스트럭터, 컨스트럭터 시즌, 팀 계보, 시즌, 엔진 시즌, 규정 연도)는 항목 순서를 고정한다. 목록 페이지는 제목 → 요약 줄 → 필터 줄 → 표다.

체코지수(`/chekoji/`)는 메뉴에 두지 않고 홈 바로가기, 시즌 캘린더의 체코지수 칸(2014–2025), 검색의 "페이지" 묶음에서 연결한다. 순서는 제목 → 요약 줄 → 대회별 점수 표(시즌 선택) → 시즌별 분포 → 항목과 비중 → 점수가 없는 결승이다. 화면에 싣는 공식은 한 판이고 "초안"을 메타와 요약 줄에 표시한다. 추정한 값(2014–2022년 세이프티 카, 노면)은 칸에 *를 달고 표 아래 주에서 설명한다. 제목 줄(길잡이, 제목, 메타, 요약 줄)은 레드불 계열 빨강(`--chekoji-red`, #cc1e4a) 띠에 흰 글자로 둔다(2026-11-26 사용자 지정, `PageHead tone="red"`). 다른 페이지와 데이터에는 이 색을 쓰지 않고, 팀 로고와 공식 이미지는 쓰지 않는다.

## 구성 요소

| 구성 요소 | 모양 |
|---|---|
| `PageHead` | 길잡이, 제목, 메타, 요약 줄(또는 `box`일 때 요약 표와 정보 표). 리드 문단 없음 |
| `Section` | h2와 메타. 요약 문장 없음 |
| `Tiles` | 요약 표(머리 칸 한 줄, 값 칸 한 줄, 값 아래 작은 보조 글) |
| `DataTable` | 머리 회색 띠, 위 1px 잉크, 행 헤어라인, 숫자 열 오른쪽 맞춤, `rowId`로 행 앵커 |
| `Figure` | 제목(14px), 범위 줄(범위와 단위만), "차트 · 표" 글자 탭, 범례, 차트, 그 아래 주. 부제와 출처 줄 없음 |
| `Note` | 주 한 문장. 묶음(.notes) 앞에 "주"가 한 번 붙는다 |
| `SourceLine` | 화면에 내지 않는다. 데이터원 키만 남겨 꼬리말 "자료" 줄을 만든다 |
| `Seg` | 글자 탭. 고른 칸은 굵은 잉크에 2px 밑줄 |
| `LinkPick`, `details.more` | 글자 단추. 펼치면 링크 목록·남은 행 |
| `EmptyState` | 위아래 헤어라인 사이 한 줄 |
| `Notice` | 회색 바탕 안내 줄 |

## 전역 검색

- 색인: 빌드 때 `src/pages/data/search.json.ts`가 드라이버, 컨스트럭터, 팀 계보, 시즌, 대회(시즌 쪽 캘린더 행 `#r<라운드>`), 엔진 시즌, 규정 연도로 만든다.
- 맞추기: `src/lib/search.ts`. 글자는 `fold()`(소문자, 발음 구별 기호와 문장부호 제거)로 맞추고, 검색어의 낱말은 모두 이름이나 다른 이름(약어, 영문, 한국어 대회명, 국적)에 맞아야 한다. 점수는 첫머리 > 낱말 첫머리 > 포함이고 이름에 맞으면 두 배다.
- 머리 칸: `/`로 초점, 화살표와 Enter, Esc. 결과는 종류별 묶음(묶음마다 6개). 모든 결과는 `/search/?q=`에 있다.

## 주

- 해석을 바꾸는 정의, 예외, 자료 한계만 한두 문장으로 쓴다. 범례·축을 되풀이하거나 방법론의 긴 정의를 옮기지 않는다.
- 굵은 머리말 없이 문장만 쓴다. 묶음 앞의 "주"는 CSS가 붙인다.

## 자료 표기

- 그림과 표의 `source`/`asof`는 화면에 나오지 않는다. `lib/sources.ts`의 `citeKeys()`가 데이터원 키를 고르고, 빌드 뒤 `scripts/page-sources.mjs`가 페이지에 쓰인 데이터원만 꼬리말 "자료" 줄에 남긴다.
- 데이터원 전체, 범위, 기준일 표는 /about/sources/에 둔다.

## 문구

CLAUDE.md "UI 문구 규칙"을 따른다. 페이지가 자기를 설명하는 문장, 표준 조작의 사용법, 범례를 되풀이하는 문장, 개발 용어를 화면에 쓰지 않는다.
번역투 고유어 동사(쓰다, 재다, 세다, 싣다, 견주다, 잡히다, 가르다, 찍다, 잇다, 칠하다, 담다)를 습관처럼 쓰지 않는다. 사용, 측정, 집계, 수록, 비교, 포함, 판정, 표시, 연결 같은 통계·스포츠 기사 어휘를 쓴다. 화면에서 "쪽"은 "페이지", "고르기"는 "선택", "거르기"는 "필터", "찾기"는 "검색"이다.
